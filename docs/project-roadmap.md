# Project Roadmap

## Phase 1: Minimal Temp Mail Browser
Status: Complete

- Receive emails through SMTP.
- Store emails in SQLite.
- Display email list in browser.
- Show detail modal.
- Delete emails.

## Phase 2: Inbox Productivity
Status: In Progress

- Search/filter by sender or recipient address: Complete.
- Auto-refresh inbox: Complete.
- 2FA/TOTP quick generator: Complete.
- Saved mailbox sidebar and save modal: Complete.
- Configurable domain display: Not started.

## Later Ideas
- Edit saved mailbox reason text.
- Export or archive messages.
- Optional deployment hardening beyond reverse-proxy basic auth.
